# Eastventura — 3va.id (offline website prototype)

## Files
- `index.html` — the website HTML, CSS and JavaScript.
- `eastventura-logo.png` — your transparent PNG logo, used in the header and footer. Keep this file beside `index.html`.

## Open offline
Open `index.html` in Firefox or another modern browser. No internet connection or installation is required.

## Important prototype limitations
This is a front-end demonstration, not a live property marketplace:
- All property listings and prices are fictional examples.
- Login and role selection are demonstrations only. There is no real authentication or private admin/member directory.
- Enquiry form does not send or store messages.
- No database, payment processing, legal verification, or file upload is connected.
- Do not publish private owner details, certificates, identity documents, passwords, or confidential information.

Before public launch, replace sample listings, contact details, legal claims and prices with verified information. Obtain qualified legal review for property and permit descriptions.

## Edit
Open `index.html` with a text editor. Search for `const listings=[` to edit sample property data. Keep `eastventura-logo.png` in the same folder as `index.html`.

## Publish with GitHub Pages (later)
1. Sign in to your own GitHub account.
2. Create a **public** repository named `3va-Web` (or another name).
3. Upload both `index.html` and `eastventura-logo.png` to the repository root. `README.txt` is optional.
4. Open repository **Settings → Pages**.
5. Select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
6. Wait for GitHub Pages to publish. The URL is usually `https://USERNAME.github.io/REPOSITORY/`.
7. Public repositories are visible to everyone. Never upload secrets or private client data.
