# Eastventura — 3va.id (Updated Website Prototype)

## Files in this package
- `index.html` — The updated website HTML, CSS, and JavaScript featuring:
  * 3-Tab Member Portal (`Owner`, `Buyer`, `User Service`) with dynamic dropdowns
  * 4-Step Owner & Developer Listing Upload Form (Role & Asset Category, Specifications & Surroundings, Private ATR/BPN Legal Verification, Media & Digital Commission Agreement)
  * Conditional Developer/Subdivision fields & Building Specifications (`Land & Property`)
  * Strict `Nett Price` & `Fix Price` classifications with interactive explanation pop-ups
  * Competitive Direct Owner commission tier (3% / 2.5% / 2%) and 50:50 Co-broking/Auction split
  * Buyer KYC + Digital NCNDA (24-month anti-circumvention) & Service User budget/timeline qualification
- `README.txt` — Setup and GitHub Pages deployment guide.

## Important Note on Logo
Keep your existing `eastventura-logo.png` file in the exact same folder alongside this new `index.html` file so the header and footer logos display properly.

## Open Offline in Firefox
1. Extract `3va-Web.zip`.
2. Place `eastventura-logo.png` into the extracted `3va-Web` folder alongside `index.html`.
3. Right-click `index.html` -> Open With -> Firefox Web Browser.

## Publish to GitHub (`ariwibowo-ai/3va-Web`)
1. Sign in to GitHub (`https://github.com/ariwibowo-ai/3va-Web`).
2. Click **Add file** -> **Upload files**.
3. Drag and drop the new `index.html` (and `README.txt` if desired) into the repository root.
4. Click **Commit changes** and wait 1-2 minutes for GitHub Pages to update.
